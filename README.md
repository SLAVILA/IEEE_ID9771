## Abstract

This repository provides the source code and associated data structure to perform a time-series analysis on a comprehensive set of economic and Brazilian energy sector variables. The primary analytical method involves applying a 365-day rolling window to calculate two key metrics of dependency: Spearman's Rank Correlation and Mutual Information. The objective is to dynamically observe and visualize the evolution of relationships between these variables over a specified period, allowing for an in-depth study of their interdependence.

This repository is structured to ensure the reproducibility of the results. Below is a description of all files and directories.

## Installation and Execution

To reproduce the analysis, please follow these steps:

1. **Clone the Repository**
Clone or download this repository to your local machine.
2. **Set Up the Environment**
It is strongly recommended to create and activate a virtual environment to manage the project's dependencies.Bash
    
    `# Navigate to the project folder
    cd /path/to/project
    
    # Create a virtual environment
    python -m venv venv
    
    # Activate the environment
    # On Windows:
    venv\Scripts\activate
    # On macOS/Linux:
    source venv/bin/activate`
    
3. **Install Dependencies**
With the virtual environment activated, install all required libraries using the `requirements.txt` file:Bash
    
    `pip install -r requirements.txt`
    
4. **Populate Data Directories**
Ensure that the input directories, `/linear_interp/` and `/dados_api/`, are populated with the necessary `.csv` data files as described in the "File Description" section.
5. **Execute the Analysis**
Run the main script from the project's root directory:Bash
    
    `python gerar_analises.py`
    
    The script will print its progress to the console.
    

## Output Description

Upon successful execution, the script will generate two primary output directories:

1. **`CS-linear-interp/`**: This directory contains the heatmaps from the Spearman's Correlation analysis.
2. **`MI-linear-interp/`**: This directory contains the heatmaps from the Mutual Information analysis.

Within each of these directories, three subdirectories will be created to organize the plots by the group of variables being compared against:

- `/var/`: Plots comparing each variable against the market variables.
- `/ena/`: Plots comparing each variable against the ENA (Natural Affluent Energy) and its derived features.
- `/geral/`: Plots comparing each variable against all other general variables (economic, climatic, etc.).

All figures are saved in a high-resolution `.png` format suitable for inclusion in scientific publications.
